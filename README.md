# SPARK

A minimal, fast static site built with HTML, CSS and vanilla JS. Hosted on GitHub Pages.

## Structure
- `index.html` — home
- `css/style.css` — design tokens, layout, components
- `js/main.js` — theme toggle, mobile menu, footer year
- `404.html` — not-found page

## Deploy
1. Push to a GitHub repo.
2. Settings → Pages → Source: **Deploy from a branch** → `main` / `root`.
3. (Optional) Add a custom domain via `CNAME`.
